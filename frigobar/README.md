# Frigobar — vendas no Pix e estoque

App para iPhone (PWA). Funciona offline e os dados ficam salvos só no aparelho.

## Instalar no iPhone
1. Abra o link no **Safari**: `https://felipenotari.github.io/FelipeNotari/frigobar/`
2. Toque em **Compartilhar** → **Adicionar à Tela de Início** → **Adicionar**.

## Telas
- **Vender** — toque nos produtos, confira o total e registre a venda (só Pix). O estoque baixa sozinho.
- **Estoque** — adicionar produtos (água, Red Bull…), preço, unidades, aviso de estoque baixo e **Repor**.
- **Resumo** — vendas do mês, gastos com reposição, lucro, mais vendidos e histórico por dia (excluir devolve o estoque).
- **Backup** — chave Pix, exportar/importar backup e apagar tudo.
